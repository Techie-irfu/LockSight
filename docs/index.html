2-Minute PC Setup Overview

  1. Set Up NextDNS: Create a free NextDNS profile with Pornography & SafeSearch enabled, plus a duplicate Ad-Bypass profile.
  2. Prepare Device: Temporarily remove Google/WhatsApp accounts and disable any cloned/dual apps for 60 seconds.
  3. Run One-Click Installer: Connect your phone via USB and run Setup-LockSight.bat from the latest GitHub Release ZIP.
  4. Seal & Lock: Sign back into your accounts, enter your NextDNS IDs inside LockSight, and tap Seal & Lock NextDNS Permanently.
